# Beauty of Joseon - Ecommerce Store

Ecommerce platform for Beauty of Joseon skincare products in the UAE market.
- 35 products from Noon.com with 35% markup
- Stripe payment processing
- 20 AED flat shipping fee
- Target: 100 PageSpeed Insights score

Built with:
- React 19 + TanStack Start
- Cloudflare Workers SSR
- D1 Database
- Stripe API

**Domain:** beautyofjoseon.me
**Hosting:** Vercel
